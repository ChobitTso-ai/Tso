# 三國單檔遊戲（官渡・長坂坡・赤壁）

三國演義 hub（`/threekingdoms`）底下的三款小遊戲。都是 Tso KY 自己寫的單檔 HTML（Canvas 2D、零外部資源），
併入 TSO 時沒有改寫成 React，原樣用 iframe 嵌入。

| 遊戲 | 網址 | 關卡 | 適合 |
|---|---|---|---|
| 🏯 官渡奇謀大冒險 | https://chobittso-ai.github.io/Tso/#/guandu | 4 關 | 兒童闖關 |
| 🐎 趙雲七進七出・長坂坡 | https://chobittso-ai.github.io/Tso/#/changban | 7 關 | 俯視動作 |
| ⛵ 赤壁妙計大冒險 | https://chobittso-ai.github.io/Tso/#/chibi | 4 關 | 兒童闖關 |

---

## 共通操作

- 每款都從**地圖**開始，過一關才會開下一關；過過的關可以隨時重玩
- 遊戲內左上角「↩ 地圖」回地圖；導覽列的「← 三國演義」（手機橫拿時是左上角「← 返回」）離開遊戲
- 右上角按鈕：🔊 開關語音朗讀、🎵 開關音效；官渡另有 🗣️ 可挑選裝置上最順耳的中文語音
- 瀏覽器規定要先點一下畫面才能發出聲音，所以開場要先按按鈕，聲音才會出來

## 手機版與電腦版

同一個網址，依裝置自動切換，不用選：

| 裝置 | 畫面 |
|---|---|
| 電腦、平板 | 上方導覽列＋遊戲置中 |
| 手機直拿 | 遊戲在中間，下方提示「把手機轉成橫的，畫面會更大」 |
| 手機橫拿 | 導覽列收起，高度全給遊戲；返回鍵縮成左上角「← 返回」 |
| 手機第一次點遊戲 | 進全螢幕並自動轉橫（Android）。iPhone 的 Safari 不支援網頁全螢幕，只會收起導覽列 |

手機的判斷條件是「觸控為主且螢幕短邊 ≤ 500px」，所以平板會用電腦版。

## 存檔

- 每款會自動記住「已經過了幾關」，重新整理或下次再開都會保留
- 存在瀏覽器裡（localStorage），換瀏覽器、換裝置或清除網站資料就會從頭開始
- 官渡、赤壁全破後的結局畫面有「從頭開始」可以重置；長坂坡沒有重置鈕，要清除瀏覽器的網站資料
- 存檔壞掉（數字不合理）會自動清掉從頭開始，不會卡住畫面

## 🏯 官渡奇謀大冒險

西元 200 年官渡之戰，幫曹操用四個計謀打贏兵比較多的袁紹。

| 關 | 玩法 |
|---|---|
| 一 白馬解圍 | 拖著大旗往西引開袁軍主力，距離夠遠再掉頭衝白馬 |
| 二 延津餌敵 | 丟下輜重讓追兵散開去搶，散開夠多再上馬突擊 |
| 三 官渡霹靂車 | 點箭樓發射投石，同時拖曳閃避箭雨 |
| 四 火燒烏巢 | 答對三題口令潛行過哨，再拖火把燒掉八堆糧草 |

- 操作：滑鼠或觸控拖曳、點擊；第一、三關可用 ← → 方向鍵；地圖上可按 1～4 選關
- 史料：關卡依《三國志》記載設計（荀攸「分其勢乃可」、「此所以餌敵」、袁紹眾號曰「霹靂車」等），
  不適合兒童的內容即使史有明載也排除

## 🐎 趙雲七進七出・長坂坡

以《三國演義》第四十一回為本，化身趙雲在亂軍中七進七出。

| 進 | 關卡 | 玩法 |
|---|---|---|
| 一 | 尋主 | 在亂軍中搜尋、找到主公 |
| 二 | 救甘夫人 | 護送甘夫人，顧好她的安危條 |
| 三 | 救糜竺 | 頭目單挑：看紅扇蓄力預警→閃開→趁破綻反打，斬將後護送 |
| 四 | 奪青釭 | 夏侯恩背著青釭劍在樹林裡躲，切角抄路＋衝刺攔截奪劍 |
| 五 | 懷阿斗 | 站綠圈推牆掩井，懷抱阿斗突圍（之後自己挨打會傷到阿斗） |
| 六 | 斬四將 | 穿過陷馬坑、擊退四將，張郃是血厚難纏的 mini-boss |
| 七 | 過橋 | 長坂橋對話解謎，張飛三聲怒吼退敵，不用戰鬥 |

- 操作：按住拖曳＝往那個方向移動；輕點一下＝衝刺或揮擊（掉進陷坑時是躍出）。電腦也可以用 WASD／方向鍵移動、空白鍵代替輕點
- 跨關強化：第四進拿到**青釭劍**後，雜兵一擊即潰、揮擊範圍變大；第五進之後**懷抱阿斗**，只能單手揮擊，自己挨打會扣阿斗的安危，歸零就失敗
- 史料：劇情出自《三國演義》（小說）。第六進依史實區分強弱：張郃是曹魏「五子良將」之一，所以設為硬底子並以撥馬敗走呈現

## ⛵ 赤壁妙計大冒險

西元 208 年赤壁之戰，幫孫權和劉備用四個妙計打贏曹操。結局是曹操撤退，走卡通、非暴力路線。

| 關 | 玩法 |
|---|---|
| 一 草船借箭 | 划草船接普通箭（每支隨機 +1～5），閃開火箭，接滿 67 支過關；有 5 艘草船 |
| 二 鐵索連環 | 發亮的船漂到對齊虛線時點畫面，把 8 艘船依序鏈起來；點錯會用掉鐵鏈（共 5 條） |
| 三 借東風 | 一直點畫面搧風，把風推向曹營，撐住集滿東風條；中途會有逆風 |
| 四 火燒連環船 | 拖著火船往上衝，撞遍 6 艘敵船點火，閃開巡邏船；有 5 艘火船 |

- 操作：滑鼠或觸控；第一關可用 ← → 方向鍵、第三關可用空白鍵搧風；地圖上可按 1～4 選關
- 史料：「草船借箭」「借東風」是《三國演義》的小說情節，不是正史《三國志》的記載；赤壁之戰本身是史實，
  火攻與連環計的細節正史和演義有出入。遊戲以趣味啟蒙為主，正式引用請查《三國志》

## 給維護者

### 檔案

```
tso-games/
├── public/sanguo/            遊戲本體（單檔 HTML，部署後在 /Tso/sanguo/<id>.html）
│   ├── guandu.html
│   ├── changban.html
│   └── chibi.html
└── src/
    ├── components/sanguo/
    │   ├── games.ts          遊戲清單：路由與三國演義 hub 卡片都由這裡產生
    │   └── README.md         本文件
    └── pages/
        └── SanguoGamePage.tsx/.css   外框頁：導覽列＋iframe＋手機版處理（CSS 前綴 .sanguo-*）
```

### 和作者原檔的差異

HTML 只有三處修改，每處都標「`TSO：`」註記，搜尋 `TSO：` 就能找到：

1. `<head>` 的登入檢查：沒登入直接開 HTML 會退回 TSO 登入頁
2. `#game` 的寬度加上高度限制：手機橫拿時遊戲上下不會被裁掉
3. 存進度：localStorage key `sanguo_<id>_progress`，只存已過關數

作者之後更新原檔時，拿新版替換後要把這三處補回去。

### 新增一款

1. HTML 放進 `public/sanguo/<id>.html`，補上上面三處修改
2. 在 `games.ts` 的 `SANGUO_GAMES` 加一筆（id、名稱、描述、圖示、路由、檔名）
3. 不用改 `App.tsx` 與 `ThreeKingdomsPage.tsx`；手機版自動套用
4. 三國島上的建物交給「TSO首頁整理」對話（見根目錄 `CLAUDE.md` 第 4 步）

詳細規則見根目錄 `CLAUDE.md` 第 7 節「單檔 HTML 子遊戲」。
